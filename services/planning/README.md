# P2 · Planejamento

Área reservada à passagem do contexto ao plano; implementação pendente.

Produz uma versão revisável com indicadores, fórmulas, granularidade, período, fontes, chaves, inclusões/exclusões, modelo de dados, testes de aceite e tarefas. Registra bloqueios e evidências.

O responsável técnico aprova uma versão explícita antes da execução. Alterar regras exige nova aprovação. O plano define o critério de correção, sem entregar respostas esperadas ao agente executor. Não transformar uma fala ambígua em regra confirmada.

# 03_reservada: só medição

Esta empresa existe para dar um número honesto de desempenho (K14). **Não** a use para ajustar prompts, playbook, catálogo de métricas, heurísticas do agente ou o próprio gerador a favor do agente. Se isso acontecer, ela deixa de servir para medir e é preciso criar outra empresa reservada, com outra semente e outras regras.

Limitação: o repositório é público, então a configuração e o gabarito (`evaluation/golden/03_reservada/`) **não são segredo**. A proteção precisa vir da execução: o executor não pode montar `evaluation/golden/` nem este diretório (ver `AGENTS.md` e K08/K11). Quem ajusta o agente deve trabalhar só com 01 e 02.

# Segurança

O projeto está em desenvolvimento para uma demonstração com dados sintéticos. Não há promessa de prontidão para produção ou conformidade automática com a LGPD.

- Não publique dados reais de clientes, credenciais, tokens, gravações privadas ou detalhes de vulnerabilidades em issues públicas.
- Para um problema sensível, use **Report a vulnerability**, se essa função estiver habilitada no GitHub. Caso não esteja, peça ao mantenedor um canal privado sem incluir o conteúdo sensível no pedido.
- Se um segredo vazar, interrompa seu uso e providencie a revogação/rotação no serviço de origem. Apagar o arquivo não remove o segredo do histórico nem de cópias.
- Dependências, acesso à rede, diretórios montados e permissões do executor devem ser revisados antes de qualquer uso com dados externos.

Não existem testes ofensivos autorizados contra terceiros nem canal privado confirmado por esta documentação.
